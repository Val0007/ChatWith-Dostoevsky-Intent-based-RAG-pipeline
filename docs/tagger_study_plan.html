Study · Metadata Tagging

White Nights Tagger Study

Find out why context helps literary tagging — field by field — before building retrieval on top of it.

11 phases · ablation-driven· builds on findings F1–F5· gate for V2 retrieval

Why this comes first

Retrieval built on wobbly tags just launders the wobble. We already have hints that the tagging story is subtler than "context helps" — this study turns those hints into mechanism.

F1
context-aware beat local tagging on narrative_relation — but confounded prompt + context together.
F5
The correction: holding the prompt fixed, accuracy was flat across all context arms. The prompt drove correctness; context data mainly bought stability — and single-source context sometimes misled.
F2
fields vary within a scene (speaker uniform 41%, narrative_relation only 19%) — so a scene card is the wrong granularity for chunk-level fields.
F3
theme collapse to unrequited-longing is localized to emotionally-saturated chapters (Fourth Night), not global.

The eleven phases

Measure first, then change the schema, then interrogate each field, then fix prompts, then control for confounds.

01

Context ablation preliminary: F1, F5

Run the four arms (A local · B +scenes · C +global · D both). C is the one that matters most for narrative_relation.

tells you whether context improves a field, or improves one while degrading another.
02

Don't remove speaker — split it

Replace the single field with narrating_voice + speaking_voice (allow speaking_voice = null for pure narration). Nested narration stops being forced into one label; retire the muddled "the Dreamer and Nastenka". Re-run the ablation.

tells you whether the speaker failure was a schema problem (regression disappears) or still prompt/context.
03

Separate local fields from global ones

Stop making six fields share one prompt. A local tagger (voice, characters, speaker_relation, themes, motifs) sees TARGET + immediate context; a context tagger (narrative_relation, maybe a contextual-interpretation field) sees TARGET + global map + scene. Follows directly from F1.

tells you whether decoupling removes cross-field contamination.
04

Fix themes separately preliminary: F3

Local vs +scenes vs +global vs all. Measure precision, recall, and over-application per theme — especially unrequited-longing as a global attractor: does context raise it while precision drops?

tells you whether to keep the global map out of the theme classifier.
05

Test narrative_relation at scene level preliminary: F2

Measure within-scene agreement (modal relation / chunks) across all scenes. High agreement ⇒ it's a scene property with chunks inheriting scene.narrative_relation. F2 hints it's only 19% uniform, so don't assume — measure the distribution.

tells you whether to lift the field up to the scene (a structural win) or keep it per-chunk.
06

A "no theme" discipline test

Build a set of transitions, descriptions, plot-mechanics, mundane dialogue. Measure the false-theme rate — the model should confidently return []. Context risks making every passage feel like it must carry a major theme.

tells you whether context inflates spurious tagging on empty passages.
07

Test speaker_relation separately preliminary: F2

Balanced gold across asserts / doubts / rejects / explores; compare arms. Watch explores % specifically — if it climbs with context (e.g. 18% → 31%), scene summaries are flattening stronger local stances.

tells you whether to keep speaker_relation strictly local.
08

Test stability preliminary: F5

20–30 chunks × 3–5 runs; per-field agreement. You may find e.g. speaker 98% / narrative_relation 74% / themes 68%.

tells you if a field is intrinsically noisy — you can't "fix" noise with more context.
09

Then do the prompt fixes

Only after the ablation. Speaker: distinguish narrating vs speaking vs reported speech. Themes: tag the TARGET's subject, never inherit from context; use context only to disambiguate. narrative_relation: an internal reasoning chain — (1) what proposition/feeling is in TARGET, (2) what the speaker does with it, (3) does TARGET itself establish the book's treatment, (4) if not, what does the global arc establish, (5) select — and never use target mood as evidence for unresolved.

tells you how much of each field is fixable by prompting alone.
10

Add the irrelevant-context control

A fifth arm: TARGET + same-length unrelated White Nights text. Distinguishes improvement from information vs. improvement from more tokens / richer prose. Essential for any research claim.

tells you whether the effect is real information or prompt-length artifact.
11

Report field-specific improvement, not "tagging quality"

Never a single "accuracy = 84%". Report the per-field arrows (local → context). That direction-vector is the finding.

tells you the actual result, instead of hiding it under an average.

The finding we're building toward

Global context substantially improves narrative-level judgments but provides little benefit to locally determined attributes, and can introduce thematic contamination and speaker-attribution errors.

That is a real answer to "how do you do metadata tagging well for literary works?" — a mechanism, field by field — not "our context-aware tagger got better." Only after this do we return to retrieval (the RAG Lab) on tags we actually trust.
